# Communications Workstream

Communications research now exists, and it lives in the shared research wiki
under `research/`, not in this directory. Start with the `COMM-*` claim ledger
in `research/SOURCE_INDEX.md`. The source docs are spread across
`research/economics`, `research/direct_communication`, `research/laser_comms`,
`research/competitors`, and `research/rocket_lab/neutron`. The syntheses are
`research/synthesis/comms_baseline_synthesis.md` and
`research/synthesis/comms_framework_synthesis.md`, and the thesis is
`research/vision/comms_thesis.md`.

No communications model output or communications business claim is part of the
first public data-center release. Future communications work should live as a
separate model family and code package when it is ready for review. For now,
this directory marks the workstream boundary so the public repository shape is
explicit.
